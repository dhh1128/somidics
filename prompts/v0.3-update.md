# Somidics v0.3 - Update Summary

## What Changed in v0.3

This document summarizes the changes made from v0.2 to v0.3.

### Core Bit Structure: UNCHANGED
- Still 13-bit somid + 5-bit CRC = 18 bits total
- Still 48 public zones (0-47)
- Still 262,144 values per plane
- Still 6-digit decimal format

### What's NEW in v0.3

#### 1. Context-Dependent Bit 12 Encoding

**Bit 12 now has different meanings depending on Type and Texture:**

**For Natural (Type=00) and Scar (Type=01):**
- Bit 12 = Multiplicity (0=single, 1=cluster)
- Same as v0.2

**For Tattoos (Type=11, Texture=10):**
- Bit 12 = Writing indicator (0=no writing, 1=has writing)
- NEW in v0.3
- Allows "Tattoo with writing on left forearm" vs "Tattoo without writing"

**For Piercings (Type=11, Texture=11):**
- Bit 12 = Multiplicity (0=single, 1=multiple)
- Makes sense for piercings (e.g., "Three piercings in left ear")

**For Missing (Type=10, Texture=00):**
- Bit 12 = 0 (unused, set by convention)
- Missing is binary, no need for additional info

**For Anomalous (Type=10, Texture=01/10/11):**
- Bit 12 = Intensifier (0=mild, 1=severe)
- NEW in v0.3
- Allows "Mild webbing" vs "Severe webbing"

#### 2. Missing/Anomalous Texture Repurposing

**For Type=10, texture bits now indicate subtype:**
- 00 = Missing (absent tissue)
- 01 = Extra (webbed fingers, extra digit, cauliflower ear)
- 10 = Fused (syndactyly, connected parts)
- 11 = Deformed (bent finger, misshapen ear)

**In v0.2:** Texture was always 00 by convention (wasted bits)
**In v0.3:** Texture provides 4-way discrimination for rare but important cases

#### 3. Refined Entropy Analysis

**v0.2 claimed:** ~11.9 bits effective entropy
**v0.3 reality:** ~11.7 bits effective entropy

The v0.3 analysis is more conservative and accurate:
- Better modeling of correlations
- More realistic zone distribution estimates
- Accounts for size distribution skew

But v0.3's enhancements partially recover the loss:
- Tattoo writing bit: +0.12 bits average
- Anomalous intensifier: +0.06 bits average

**Result:** ~1-in-3,300 discrimination (down slightly from v0.2's optimistic 1-in-3,870, but more realistic)

### Migration from v0.2 to v0.3

**Breaking changes:**
1. Tattoos must be re-encoded to capture writing indicator
2. Anomalous features must be re-encoded to capture subtype and intensifier
3. Missing parts must explicitly set texture=00

**Non-breaking:**
- Natural marks and scars work the same (multiplicity already existed conceptually)
- All valid v0.2 somidics remain structurally valid in v0.3
- Semantic interpretation may differ slightly

**Recommendation:** Re-issue credentials with v0.3 encoding when practical

## Key Improvements in v0.3

1. **Smarter encoding:** Context-dependent bits extract more value from the same structure
2. **Better semantics:** "Tattoo with writing" and "severe webbing" are natural and meaningful
3. **Stability maintained:** All enhancements are stable over time (unlike color)
4. **No complexity increase:** Same 13-bit somid, just smarter interpretation

## Design Philosophy

v0.3 embodies "don't fight the correlations - exploit them":
- Since tattoos are identified by Type+Texture, repurpose bit 12 for writing
- Since anomalies are rare, give them maximum discrimination when present
- Since missing is binary, don't waste bit 12

This is more sophisticated than v0.2's uniform approach, but maintains the core simplicity.
